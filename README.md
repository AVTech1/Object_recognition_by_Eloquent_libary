# Object_recognition_by_Eloquent_libary
We use the Eloquent libary and the EdgeImpulse website to recognition green poles with an XIAO ESP32S3 Sense board
Based on the post on the EloquentArduino website i have done and go through the whole proces of learning how to use the libary and the EdgeImpulse website to train my microcontroller to recognition a green pole. Fun to do with very good result:
https://eloquentarduino.com/posts/esp32-cam-object-detection
